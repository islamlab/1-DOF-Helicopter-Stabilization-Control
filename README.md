# 1-DOF Helicopter Stabilization & Control

This project focuses on the design, implementation, and experimental validation of a 1-DOF helicopter pitch stabilization system. The primary objective is to regulate and track a desired pitch angle about a fixed pivot using brushless DC (BLDC) motors and an inertial measurement unit (IMU).

## 📌 Project Overview
The control of helicopter systems is a classical problem in control engineering due to their open-loop instability, nonlinear dynamics, actuator constraints, and sensitivity to sensor noise. This project employs state-space modeling, Kalman filtering for state estimation, PID-based state feedback, and gravity feedforward compensation to achieve stable and accurate control.

The system leverages a Kalman filter to fuse noisy accelerometer and gyroscope measurements from an MPU6500 sensor to provide accurate state estimation. The control signal is then sent to an electronic speed controller (ESC) driving a brushless DC (BLDC) motor.

## 🧮 Mathematical Modeling
The pitch dynamics of the 1-DOF helicopter are modeled using rotational mechanics:

$$J\ddot{\theta} + b\dot{\theta} + mgl\sin(\theta) = \tau$$

Where:
* $\theta$: Pitch angle (rad)
* $\dot{\theta}, \ddot{\theta}$: Angular velocity and angular acceleration
* $J$: Moment of inertia about the pivot
* $b$: Viscous damping coefficient
* $m$: Effective mass
* $g$: Gravitational acceleration
* $l$: Distance from pivot to center of mass
* $\tau$: Control torque generated by the motor(s)

### Control Law
A linear state-feedback controller is applied:

$$u = -k_{1}e_{\theta} - k_{2}e_{\dot{\theta}} - k_{i}\int e_{\theta}dt + u_{ff}$$

Where $u_{ff}$ is the feedforward term compensating for gravity.

## 🛠️ Hardware Requirements
* Arduino Uno 
* MPU6500 IMU
* One or two BLDC motors
* Electronic Speed Controller (ESC)
* External motor power supply

## 💻 Software & System Architecture
* **Embedded Control (Arduino C++):** Runs the control loop at **100Hz**. Handles I2C communication with the MPU6500, applies the Kalman Filter, computes the LQR/State-Space logic, and outputs constrained PWM signals to the ESC.
* **Monitoring & UI (MATLAB):** A custom MATLAB UI communicates with the microcontroller via Serial. It provides real-time plots of measured angle, reference angle, and PWM signal. 

## 🚀 How to Run the Project
1. **Upload Arduino Code:**
   * Open the Arduino IDE and connect your board via USB.
   * Upload the provided Arduino code.
   * **Important:** Close the Arduino Serial Monitor after uploading to free the COM port.
2. **Hardware Setup:**
   * Connect the MPU6500 using I2C.
   * Connect ESC signal wires to the Arduino PWM pins.
   * Power the motors using an external supply and place the helicopter in a safe position.
3. **Run MATLAB Interface:**
   * Open MATLAB and run the monitoring script.
   * Use the slider or numeric input to set the desired pitch angle. The system will smoothly track the reference.

*Note: Always upload Arduino code before starting MATLAB, and observe safety limits when operating the motors.*
